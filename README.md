# Bin The Copper

Retro street-fighter browser game. Fight the copper with wheelie bins!

## Play online

After GitHub Pages is enabled, play here:

**https://YOUR-GITHUB-USERNAME.github.io/bin-the-copper/**

(Replace `YOUR-GITHUB-USERNAME` with your real username.)

## Controls

| Key | Action |
|-----|--------|
| Arrow keys | Move, jump (↑), duck (↓) |
| Z | Swing bin |
| X | Throw bin |
| Walk into your green bin | Equip |
| Enter | Continue between rounds |
| M | Mute sound |

## Run locally

Open `index.html` in any modern browser (Chrome, Edge, Firefox).

## Files

- `index.html` — main page
- `game.js` — game logic
- `sprites.js` — characters & UK bins
- `audio.js` — sound & music
- `style.css` — UI styling
